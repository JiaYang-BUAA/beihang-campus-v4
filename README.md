# 北航三校区 V4 · 3D 校园

学院路、沙河、杭州国际校园的轻量三维浏览网站。所有模型和 Three.js 依赖同源提供，按校区下载，无外部 CDN 或字体依赖。

网站：https://jiayang-buaa.github.io/beihang-campus-v4/

本仓库根目录为静态发布文件。GitHub Pages 使用 main 分支根目录发布。模型以 gzip 保存，浏览器下载后解压为 GLB。需要支持 WebGL 2 与 DecompressionStream 的现代浏览器。

2026-10-10 发布前已检查三校区加载、地标定位、旋转缩放、自动环绕、说明弹窗以及 390×844 窄屏布局。浏览器解析的三角面分别为 1,166,356、1,092,649、825,272；这不是物理手机性能实测。

模型制作于 2026-10-09，照片日期未知。建筑尺度、细节及植物分布包含推定；这是外观近似模型，并非官方导航、测绘或 BIM，不应用于施工或安全通行。

运行依赖许可证位于 assets/vendor/。此版本仅含轻量模型。
